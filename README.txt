IMPORTANT SECURITY LIMITATION
This is a static GitHub Pages site. The entry/admin password is in client-side JavaScript and therefore is not real security. Local edits are stored only in that browser and do not sync to GitHub or other devices. Do not store confidential files or secrets here. For genuinely owner-only administration and synced content, connect a backend/authentication service (e.g. Supabase) and enforce permissions server-side.
